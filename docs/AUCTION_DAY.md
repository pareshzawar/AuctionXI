# Auction-day checklist

## Information to collect beforehand

- [ ] Tournament name, venue, date, time, organiser
- [ ] Number of teams, team names, colours, owners, captains
- [ ] Format (overs, players per side) → decides min/max squad
- [ ] Player registrations: name, role, batting/bowling style, age, flat/locality, photo (optional), past stats (optional)
- [ ] Category of each player (decided by the committee) and base prices
- [ ] Retained players (captains/owners/icons) and their price
- [ ] Purse, increments, timer, unsold policy (see [RULES.md](RULES.md)) agreed with all captains
- [ ] Who is the auctioneer (admin), who is the backup (co-admin)

Tip: collect registrations with a Google Form → the responses go to a Google Sheet → rename the columns to match the template → *File → Download → CSV*.

## A day before

- [ ] Upload teams and players, check every name and category, then **lock** the list
- [ ] Do a mock auction with 2–3 players, then **create a fresh auction** for the real one (or undo the mock sales)
- [ ] Send each captain their code ("Copy message" in Access & sharing)
- [ ] Ask captains to join on their phones and check they appear as "Signed in"
- [ ] Give the co-admin the admin code

## At the venue

- [ ] Laptop for the admin (charged, on mains power), a stable internet connection plus a phone hotspot as backup
- [ ] Projector/TV showing the **Big screen** link (full-screen with F11)
- [ ] QR code from Access & sharing printed or shown at the start so the audience can join
- [ ] Mic for the auctioneer
- [ ] Announce the rules once before starting

## During

- `N` next player → bids → `S` sold / `U` unsold
- If a captain's phone dies: the auctioneer bids for that team from the control room
- If a wrong sale happens: **Undo last sale** immediately
- When the round finishes: **Start round 2** to re-auction unsold players

## After

- [ ] **Finish auction**
- [ ] Share the results link and a screenshot in the group
- [ ] Download the **Full auction JSON** and commit it to `archive/` so the results stay online permanently
