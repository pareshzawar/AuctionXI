How it works

  1. Admin creates an auction, sets rules (purse, squad size, base prices, bid increments, timer).
  2. Download the players CSV template and teams template, fill them in Excel / Google Sheets, upload.
  3. Review and edit players, then lock the list - it is now fixed for this auction. A new auction starts with a fresh upload.
  4. Share the auction code. Captains enter their secret team code to bid; everyone else watches.
  5. Run the auction from the admin control room, then export results and archive them.
